# ✨ 个性星球 · 互动粒子主页

> 一个炫酷、可交互的 GitHub Pages 静态网页，包含动态粒子星系、实时时钟和点击爆炸特效。

## 🎨 功能特色

- 🌌 **动态粒子星系** – 数百颗彩色粒子缓慢旋转，随鼠标移动而偏移，形成梦幻星空。
- 🕒 **实时渐变时钟** – 彩色渐变数字，每秒自动更新，清晰美观。
- 💥 **点击爆炸特效** – 点击页面任意位置，绽放绚丽的彩色粒子爆炸效果。
- 🎲 **随机个性签名** – 每次点击都会切换一句随机的格言或心情语。
- 📱 **全设备适配** – 完美支持电脑、平板和手机，触摸屏幕同样可以触发交互。
- 🌐 **零成本部署** – 依托 GitHub Pages 免费托管，无需服务器。

## 📦 快速部署（3 步）

1. **Fork 或新建仓库**  
   在 GitHub 上新建一个仓库（公开/私有均可），或直接 Fork 本项目。

2. **上传 HTML 文件**  
   将 `index.html` 文件放入仓库根目录（如果你下载了本仓库，直接推送即可）。

3. **开启 Pages**  
   - 进入仓库 `Settings` → `Pages`。
   - 在 **Branch** 选项中选择 `main` 分支，点击 **Save**。
   - 等待 1~2 分钟，你的页面就会在指定链接生效。

## 🛠️ 自定义指南

你可以轻松修改页面内容，让它更符合你的个性：

### 修改个性签名列表

打开 `index.html`，找到如下数组，增删或替换其中的句子：

    const slogans = [
        '「 保持好奇，永远年轻 」',
        '「 代码是诗，逻辑是韵 」',
        '「 今天也是闪闪发光的一天 」',
        // …… 添加你的句子
    ];

### 调整粒子数量与颜色

- 搜索 `STAR_COUNT` 可改变星星数量（默认 400）。
- 搜索 `hsl(${200 + Math.random() * 60}` 可调整星星色相范围（偏蓝调）。

### 修改时钟样式

在 CSS 中查找 `.time` 类，调整渐变色或字体大小：

    .time {
        background: linear-gradient(135deg, #f093fb, #f5576c); /* 修改为你喜欢的颜色 */
    }

### 关闭或开启特效

如果你想禁用点击爆炸或鼠标跟随，可以注释掉相关的事件监听代码（注释已写在 JS 中）。
